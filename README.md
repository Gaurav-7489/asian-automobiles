# Asian Automobiles

Frontend-first website build for Asian Automobiles.

Stack: Next.js, TypeScript, Tailwind CSS, Framer Motion, Lucide React.

Current phase: UI/UX only. Forms, CMS, analytics, CRM, WhatsApp routing, storage and other integrations are intentionally placeholders.

Run locally with npm install, then npm run dev.

Design direction follows the supplied Asian Automobiles Website Blueprint and uses the Fixonic site as visual inspiration rather than copying its content.

Production build verification is enforced through GitHub Actions.

Final premium build verification.
